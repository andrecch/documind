**Tech Stack (M2):** lo de M1 (Nest 11 + Drizzle + pgvector + Next 15 + zustand + next-intl) + `node:crypto` AES-256-GCM + SSE sobre HTTP/1.1 (sin librerías extra) + regex de citación en servidor.

### Task 2: POST /search (M2.1)

**Files:** `apps/api/src/search/*`, `apps/api/src/documents/*` (GET :id), `app.module.ts`, tests

- [x] **S1:** `GET /documents/:id` → `DocumentResponseDto` (usa `documents.getOrFail`; sirve para abrir ficha desde citas).
- [x] **S2:** `search.service.ts`: `search(req: SearchRequest)` — (a) `const [qv] = await provider.embed([req.query])` con try/catch → `SEARCH_EMBED_ERROR` (502) si `LlmProviderError`; (b) SQL raw (POOL) con kNN:

```sql
SELECT c.id AS chunk_id, c.document_id, c.extraction_id, c.kind, c.item_index, c.content,
       1 - (c.embedding::halfvec(2048) <=> $1::halfvec(2048))::float8 AS similarity,
       d.filename, d.created_at, e.doc_type
  FROM document_chunks c
  JOIN documents d ON d.id = c.document_id
  JOIN extractions e ON e.id = c.extraction_id
 WHERE ($2::text IS NULL OR e.doc_type::text = $2)
   AND ($3::timestamptz IS NULL OR d.created_at >= $3)
   AND ($4::timestamptz IS NULL OR d.created_at <= $4)
 ORDER BY c.embedding::halfvec(2048) <=> $1::halfvec(2048)
 LIMIT $5
```

vector literal: `` `[${qv.join(",")}]` ``; (c) post-proceso: dedup por `document_id` conservando el mejor hit; por cada documento con hits tipo `item` sin su padre, hacer fetch del padre (`WHERE document_id = ANY(...) AND kind='document'`) y añadirlo con `similarity: null`-like (usar `null` en el DTO → tipo `similarity: number | null` en shared) y content; orden final por similitud desc (padres añadidos al final de su doc). `tookMs` = performance.now diff.
