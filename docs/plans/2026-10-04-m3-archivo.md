# M3 — Archivo: historial avanzado, re-edición de archivados y export — Plan de Implementación

> **For agentic workers:** REQUIRED SUB-SKILL: usa la skill local `executing-plans` para ejecutar este plan tarea por tarea. Steps con checkbox (`- [ ]`).
> **Nota de commits:** política aprobada 2026-10-04: commit semántico por task tras pasar gates SIN preguntar (Conventional Commits, `main`); push únicamente al finalizar Task 7 (cierre).
> **Creado:** 2026-10-04, tras cerrar M2 (`docs/plans/2026-10-03-m2-recovery.md`). El plan se elaboró en una sesión de preparación con el mapa del código real (read-only) y 4 decisiones grill del usuario.

**Goal:** Capa de archivo sobre lo construido: historial avanzado (filtros tipo/estado/fecha + búsqueda por filename + paginación manual + eliminar documento con confirmación inline), re-edición de archivados en la web en modo explícito (la API ya soporta PATCH confirmed con re-embed desde M1) y export de la ficha (JSON completo + CSV de ítems).

**Architecture:** sin migraciones (no hay tablas nuevas). API suma `DELETE /documents/:id` (unlink de disco + delete con cascadas FK ya existentes) y el filtro `q` (filename ILIKE) en `GET /documents`. La web reescribe `history-list.tsx` con barra de filtros talonario + «VER MÁS», añade modo edición al `ficha-form` (patching a `/extraction/confirmed` cuando `status=confirmed`) y `lib/export.ts` genera JSON/CSV en cliente (Blob + a[download]) — sin endpoints nuevos para export.

**Tech Stack (M3):** lo de M1+M2 (Nest 11 + Drizzle + pgvector + Next 15 + zustand + next-intl). Sin dependencias nuevas (CSV a mano, JSON con `JSON.stringify`).

### Task 2: API — DELETE /documents/:id (M3.1)

**Files:** `apps/api/src/documents/{documents.service.ts,documents.controller.ts,dto.ts,storage.ts}`, `apps/api/test/documents.e2e-spec.ts`

- [x] **S1:** `storage.ts` añade:

- [x] **S2:** `documents.service.ts`:
  ```ts

    const row = await this.getOrFail(id);

    await this.storage.remove(row.storagePath);
  ```

## Riesgos y mitigaciones

| Riesgo                                                    | Mitigación                                                                                       |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| DELETE deja huérfano en disco si falla el unlink          | Borrar row primero, unlink después con `force: true`; huérfano aceptado (disco local, logs)      |
| Edición archivada dispara PATCH draft por accidente (409) | El form enruta por estado: confirmed → patchConfirmed; fallback si cambió el estado entre medias |
| CSV con acentos roto en Excel                             | BOM `\uFEFF` + sep `;` + test unit del BOM/escape                                                |
| Filtros con fechas inválidas en la UI                     | `type="date"` nativo + normalización ISO antes de serializar (patrón de /search de M2)           |
| next build OOM (12 GB)                                    | Receta de gates con `--concurrency=1` + tope de heap (AGENTS.md)                                 |
